        Conexión

        Cómo conectar tus cuentas

        1. Copia tu Access Token de Mercado Pago (Tus integraciones → Credenciales) y tu llave secreta de Stripe (Desarrolladores → Llaves de API). Para probar usa las de prueba (TEST-… y sk_test_…).
        2. Guárdalas como secretos de Supabase, nunca en esta página:
          supabase secrets set BN_MP_ACCESS_TOKEN=… BN_STRIPE_SECRET_KEY=… BN_ORIGENES=https://tu-dominio.com
        3. Publica la función: supabase functions deploy beatynails-pagos --no-verify-jwt
        4. Pega aquí su dirección y la llave pública, toca Probar conexión y quita el modo de prueba.

        Cómo funciona el acceso

        La contraseña protege el panel en este navegador, donde también se guardan las citas y ventas. En otro equipo o navegador se crea su propio acceso la primera vez. Si olvidas la contraseña, en la pantalla de entrada usa "¿Olvidaste tu contraseña?" con tu código de recuperación.
